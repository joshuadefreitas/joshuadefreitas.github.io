How I work

Make the invisible legible.

The hard part is rarely choosing a model. It’s shaping the surrounding system so the result can be trusted, tested, and handed to someone else without a lengthy explanation.

01Start with the boundary

Define the data contract, the consumer, and the evidence. Complexity comes later, if at all.

02Make behavior observable

Reproducible runs, explicit decisions, results another person can inspect and challenge.

03Earn the abstraction

The first system should be narrow enough to be right. Depth comes when the evidence demands it.

About
