How I work

Clarity is an engineering feature.

I like work where the hard part is not only choosing a model, but shaping the surrounding system so the result can be trusted, tested, and used.

01Start with the boundary

Define the data contract, the consumer, and the evidence before adding complexity.

02Make behavior observable

Prefer reproducible runs, explicit decisions, and results that another person can inspect.

03Earn the abstraction

Keep the first useful system narrow, then deepen it where the work proves the need.
