Agent run recorder

When you run several coding agents at once, it gets hard to say what each one did, which ones finished, and which ones stopped partway. This keeps that record, and tells you where to pick up.

Version 1 · private for nowWorking name: agentctlPython · standard library only

What it does

  • LifecycleWhether a run is running, finished, stale or in conflict, decided from evidence (an exit marker, a live process) rather than guessed.
  • LinkageGroups the runs that belong to one unit of work, so a build, its reviews and its fixes read as one story.
  • ProvenanceWhich model and provider produced each run, and what a reviewer concluded.
  • InterruptionsSpots runs that stopped on a usage limit rather than failing, and prints the command that would resume them.

What it deliberately doesn’t do

  • It only readsIt never launches an agent, sends a prompt, or writes anything back.
  • It never resumes anythingResume commands are advice. It prints them; you decide.
  • It keeps to metadataBy default the record comes from run metadata and process state, not from transcripts or credentials.
  • It doesn’t guessWhere the evidence is thin it says “unknown” instead of inventing a status.

It is built and tested: 71 automated tests and 22 acceptance checks against live runs. It is not released. The licence is undecided, and the name is a working name that will probably change.
