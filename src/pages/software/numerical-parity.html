Numerical parity

Run the same small computation on a CPU and on different graphics chips, and ask whether the answers are the same. It is harder than it sounds, and “the same” turns out to mean several different things.

Early prototype · private for nowWorking name: parityRust · wgpu

The idea

Floating-point arithmetic is deterministic on one machine and surprisingly slippery across several: a fused multiply-add here, a different order of summation there, a driver that rounds differently. So before running anything, the tool requires a statement of what counts as equivalent for that computation: exactly equal integers, or floating-point results within a stated number of units in the last place.

Then it runs a plain CPU reference and each device, and reports pass, fail, incomparable or error per device, with the first point where they diverge, whether repeated runs agree, and enough about the device and driver to know when a result has gone stale.
