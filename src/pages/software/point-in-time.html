Point-in-time auditor

A number can describe last quarter and still not have existed last quarter. This checks whether an analysis used a value before anyone could have known it.

Early prototype · private for nowPython

What it checks

  • AvailabilityGiven a table of values with the dates they became known, which ones could an analysis legitimately use at a given cutoff?
  • RevisionsHow large and how late the corrections to a series are, which is often the quantity you need.
  • Forecast inputsWhether each input a forecast used was already known at the stated origin, and whether the target was.
  • Leaks you can’t seeA perturbation test: change the future, and see whether a forecast changes.

Where it stands, and what it can’t do

It is an early prototype, in active development, and not public. It audits consistency with the availability dates you give it. It does not discover those dates, so it can’t tell you the true release time of a data point, and its answers are only as good as the vintages it is shown.
